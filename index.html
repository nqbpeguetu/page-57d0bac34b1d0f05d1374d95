01 / 阅读须知

在开始之前，值得先弄明白的三件事

订阅类产品最容易产生的误会，往往不是技术问题，而是把别人的使用习惯直接套在自己身上。下面三条是这份说明的前提。

第一，套餐里的流量是每月额度，不是总量

每月额度按自然月重新计算，上月未用完的部分不会累积到下个月。所以选档位时看的应该是“平常月份用多少”，而不是“最忙那个月用多少”，也不必为了偶发的一次高峰直接跳到最高档。

第二，设备数量限制的是“同时在线”

同一时间在线的设备数受套餐约束，先后登录、退出不受影响。家里手机加平板、公司一台电脑，通常按两台算即可；若常带着笔记本和手机同时开工，就要把这一点算进档位选择里。

第三，年付是折算价格，不是另一种套餐

年付与月付在可用权益上完全一致，差别只在结算方式与折算后的数字。如果只是短期需要，月付更灵活；确定会长期使用，年付的单价才划算。请按自己的实际使用周期来判断。

03 / 客户端

客户端按平台分开说，不合成一句话

不同平台的安装入口与配置方式不同。下面按类别说明各自需要注意的地方；具体下载渠道请以你在订阅后获得的信息为准，本页不提供下载链接。

桌面端（Windows / macOS）

桌面端通常需要手动导入订阅信息。安装完成后，在客户端的订阅或配置界面粘贴订阅内容，保存并刷新一次，节点列表才会出现。

要点：先导入配置，再选节点

若列表为空，多半是订阅内容粘贴不完整，重新复制一次往往就能解决。

移动端（iOS / Android）

移动端安装后一般通过扫描或手动粘贴配置完成导入。系统可能在首次启用时要求确认相关权限，按系统提示逐项确认即可。

要点：导入后核对一次规则

切换网络环境（例如从 Wi-Fi 到移动网络）后，建议重新打开客户端确认状态。

路由器与其他设备

路由器场景一般需要设备本身支持相应的配置方式，配置位置因设备型号而异，本页不提供具体参数。

要点：先确认设备能力

如果设备不支持，改用单机客户端通常更省事，也不会额外占用套餐的同时在线名额之外的资源。

订阅信息的保存

订阅信息属于账号凭证，不要转发到公开群组或截图外传。换设备时重新导入即可，无需重复订阅。

要点：一人一份，不外传

版本更新

客户端有更新时优先升级到较新版本，再排查问题。旧版本出现的异常，往往在更新后不再复现。

要点：先升级，再排查

卸载与残留

卸载后若系统网络行为仍异常，检查系统网络设置中是否残留了相关配置项，清除后重启设备。

要点：卸载后看一眼网络设置

04 / 使用说明

从拿到订阅到正常使用，六个步骤

顺序不要跳。跳过前面任何一步，后面出问题时都会多绕一圈。

确认档位与结算周期

先按本文第 02 区块的三行权益，判断自己该落在哪一档，再决定月付还是年付。用量与设备数是两个独立判断项，别只看其中一个。

取得订阅信息

订阅完成后会得到属于你的配置内容。保存到本地文档里，不要只留在聊天记录中，以免之后找不到。

安装对应平台的客户端

按你实际使用的设备选择桌面端或移动端。安装过程中若系统提示权限确认，逐项读完再点允许。

导入配置并刷新

把订阅内容粘贴到客户端对应位置，保存后手动刷新一次。节点列表出现，说明导入成功。

选节点，做一次连通测试

先随便选一个节点打开网页，确认基本可用，再根据用途换成更合适的线路。一次只改一个变量，便于定位问题。

核对同时在线设备数

最后看一眼当前在线的设备是否超出所选档位。超出时先退出不用的设备，再看是否恢复正常。

05 / 常见问题

常见问题，分三组编号作答

问题按主题分成订阅、客户端、使用三组，编号连续。翻找时按编号定位即可。

订阅与计费

  1. 月付和年付有什么区别？

    权益完全一致，区别只在结算周期与折算价格。以旗舰版为例，月付为 ¥35 / 月，按年付为 ¥350 / 年。若使用周期不确定，月付更灵活；确定长期使用，年付的单价更低。

  2. 可以随时从一个档位换到另一个档位吗？

    可以提出变更需求，具体如何处理取决于当前所处的结算周期。本页不预设换档的差价规则，请通过工单说明你的情况，以实际答复为准。

  3. 每月额度什么时候重置？

    按自然月重置。上月未用完的额度不结转到下月，因此不建议为了“用满”而勉强使用，也不建议按最高月份的用量来选档位。

  4. 流量用超了当月额度会怎样？

    额度用尽后当月服务会受限，需要等到下个周期重置，或考虑调整到更高档位。具体处理方式以工单答复为准，本页不做额外承诺。

客户端与安装

  1. 导入订阅后节点列表是空的怎么办？

    先检查订阅内容是否完整复制，首尾都不要遗漏；再确认客户端版本是否为较新版本。两项都确认无误后刷新一次，通常即可恢复。若仍为空，提交工单并附上客户端版本与操作步骤。

  2. 同一份订阅可以同时装在两台电脑上吗？

    可以安装，但同时在线数量受套餐限制。基础版为 3 台、旗舰版为 5 台、团队版为 20 台。安装数量与同时在线数量是两回事，判断时看后者。

  3. 换新手机后需要重新订阅吗？

    不需要。在新设备上安装客户端并重新导入原有订阅信息即可，无需再买一份。旧设备若不再使用，记得退出，以腾出同时在线名额。

  4. 路由器上能用吗？

    取决于路由器本身是否支持相应的配置方式。本页不提供具体参数，也不对设备兼容性作出承诺。如果你的设备不支持，改用单机客户端通常更直接。

使用与支持

  1. 连接后网页打不开，应该按什么顺序排查？

    先换一个节点测试，再刷新订阅，然后升级客户端版本，最后重启设备。按这个顺序逐项排除，通常在前两步就能定位原因。每次只改一项，避免同时变动多个条件。

  2. 流媒体解锁指的是什么？

    基础版提供基础流媒体解锁，旗舰版与团队版为全节点原生流媒体解锁。具体哪些服务、在哪些节点生效，会随实际情况变化，本页不逐项列举，请以实际使用结果为准。

  3. 旗舰版的优先工单支持是怎么算的？

    旗舰版标注为 7×24 优先工单支持，团队版另有专属客户经理服务。优先指工单处理的先后次序，不代表问题一定能在某个时限内解决，本页不对处理时长作出承诺。

  4. 我该选哪一档？

    按两个问题判断：每月大概用多少流量，通常有几台设备同时在线。两项都偏小，基础版足够；其中一项偏大，旗舰版更稳妥；多人共用或办公场景，再考虑团队版。

读到这里，可以做个决定了

如果你已经能回答“每月用多少”和“几台设备同时在线”这两个问题，那么选哪一档其实已经清楚了。剩下的只是月付还是年付，那是结算方式的选择，不是能力的选择。

有本页没有覆盖的情况，不必猜测。把问题写进工单，说明设备、步骤和现象，比一句“用不了”更容易得到有用的答复。回到订阅方案，或者再看一遍常见问题。
